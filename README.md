# Mouse Dynamics & Hand Prediction

A class project I worked on in collaboration with another student to explore whether mouse movement patterns can be used to predict if someone is using their left or right hand.

We collected data through a web-based game where users drag six balls into a basket, then analyzed the data and experimented with machine learning models.

### My Contributions
- Cleaned and preprocessed the collected datasets.
- Analyzed mouse movement features and explored which ones were most useful for predicting hand usage.
- Trained and evaluated machine learning models, including Random Forest, and explored SVM and XGBoost.
- Created visualizations to compare left- and right-hand movement patterns.
- Investigated dataset bias, particularly how time-based features could affect predictions.
- Worked on improving feature selection to make predictions less dependent on task performance.

### Tools & Technologies
- Python and Jupyter Notebook
- Pandas and Scikit-learn
- Matplotlib and Seaborn
- HTML, CSS, and JavaScript for the web-based task

### What I Learned
This project gave me practical experience with data preprocessing, feature engineering, machine learning, and evaluating model performance. It also showed me how dataset bias can affect results and why accuracy isn't the only measure of a good model.

This is an incomplete learning project, and there's still room to improve the models with more data and testing.
